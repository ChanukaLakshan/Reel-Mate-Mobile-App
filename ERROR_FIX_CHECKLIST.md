## 📝 QUICK START GUIDE

### 1. Get API Key (5 min)
```
URL: https://www.themoviedb.org/settings/api
Steps:
  1. Click Sign Up
  2. Create account
  3. Go to Settings → API
  4. Request API key (v3)
  5. Copy the key
```

### 2. Add Key (1 min)
```
File: app/src/main/java/com/example/newreelmate/api/TMDBConfig.java

Line 15:
public static final String TMDB_API_KEY = "YOUR_TMDB_API_KEY_HERE";

Change to:
public static final String TMDB_API_KEY = "your_actual_key_here";
```

### 3. Build (2 min)
```
IDE: Android Studio
Commands:
  • Build → Clean Project
  • Build → Make Project
```

### 4. Run (2 min)
```
IDE: Android Studio
Commands:
  • Press Shift + F10
  • OR Click Run button
  • Select emulator/device
```

### 5. Test
```
Expected:
  • Toast: "Loading movies from TMDB..."
  • RecyclerView fills with movies
  • Toast: "Loaded 20 movies from TMDB"
  
Each movie shows:
  • Real title
  • Real genres (Drama, Crime, etc.)
  • Real rating (9.3/10)
  • Real poster image
```
